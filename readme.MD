# 🎵 Notas y Acordes

> **Blog web para descubrir y dar visibilidad a artistas emergentes y sus propuestas musicales.**

## 📖 Descripción

**Notas y Acordes** es un blog web dedicado a la difusión de artistas emergentes y sus propuestas musicales.

El proyecto nace con el propósito de crear un espacio digital donde nuevos talentos puedan obtener mayor visibilidad y acercar su música a diferentes públicos.

La plataforma busca destacar la creatividad, la disciplina, el proceso artístico y la identidad propia de cada autor, promoviendo contenido relacionado con artistas emergentes y sus proyectos musicales.

---

## 🎯 Misión

Impulsar la visibilidad de nuevos talentos mediante una plataforma digital que permita conocer su música, trayectoria y proyectos.

Buscamos conectar a artistas emergentes con personas interesadas en descubrir nuevas propuestas musicales, brindando un espacio organizado, accesible y respetuoso con el trabajo creativo de cada artista.

---

## 💡 Necesidad del proyecto

Muchos artistas que se encuentran iniciando su trayectoria pueden tener dificultades para encontrar espacios de difusión y llegar a nuevos públicos.

**Notas y Acordes** busca responder a esta necesidad reuniendo información sobre diferentes artistas emergentes y sus propuestas musicales en un solo sitio web.

De esta manera, los usuarios podrán explorar nuevos talentos y conocer información relevante sobre sus proyectos.

---

## 🎯 Objetivo general

Crear un blog web que sirva como espacio de difusión para artistas emergentes, permitiéndoles dar a conocer su música, trayectoria y proyectos a nuevos públicos.

### Objetivos específicos

* 🔎 Investigar y seleccionar artistas emergentes.
* 🎵 Publicar información relevante sobre sus propuestas musicales.
* 📂 Organizar el contenido mediante categorías o secciones.
* 🎨 Diseñar una interfaz atractiva, clara y fácil de utilizar.
* 🌟 Promover el descubrimiento de nuevos artistas.
* ✅ Verificar la información antes de su publicación.
* ©️ Respetar los derechos de autor y evitar contenido no autorizado.
* 🔄 Mantener actualizado el contenido del blog.

## 🚀 Ejecución del proyecto

Para visualizar el proyecto localmente:

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Entrar a la carpeta:

```bash
cd Notas-y-Acordes
```

3. Abrir el archivo:

```text
index.html
```

También puedes utilizar **Visual Studio Code** junto con la extensión **Live Server** para ejecutar el proyecto en el navegador.
